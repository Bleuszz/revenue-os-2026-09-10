# FullyRetro public store preview

Source checked 2026-09-10: https://www.ebay.co.uk/str/fullyretro

## Observed public facts

- Store has 1,062 active items and 54K historical sales at check.
- Seller location and company details are UK, while the About copy says it is the widest retro-game selection in Australia.
- Many visible titles end with an unexplained single-letter condition code such as `A`, `B`, `C` or `D`.
- Visible titles use repeated synonym strings such as `Playstation`, `PS1 Game`, or `Football Soccer 04`.

## Example title

Current: `REAL BOUT FATAL FURY (PS1 Game) Playstation A`

Proposed structure, after verifying region and condition: `Real Bout Fatal Fury PS1 PlayStation 1 Game [PAL/Region] [Condition]`

## QA flags

- Explain condition codes in the seller description and, if possible, use an eBay-recognised condition field rather than an unexplained final letter.
- Align storefront geography with the current UK seller location or explicitly explain international history.
- Remove redundant title terms only after checking which variants genuinely support search discovery.
