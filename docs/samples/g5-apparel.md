# G5 Apparel public catalogue preview

Source checked 2026-09-10: https://www.ebay.co.uk/str/g5apparel

## Observed public examples

- Top-level labels use `KID'S`, `MEN'S`, and `WOMEN'S`, while subcategories use `Mens` and `Womens`.
- Several category labels use `T.Shirts` while others use `T-Shirts`.
- The title `Mens Game Aston Pro Trousers | Waterproof | Breathable| Hunting | Shooting` lacks a space before one separator.
- Product titles mix pipes, hyphens, apostrophes, and non-apostrophe gender terms.

## Safe corrections

- Agree a consistent set such as `Kids'`, `Men's`, `Women's`, and `T-Shirts`.
- `Men's Game Aston Pro Trousers | Waterproof | Breathable | Hunting | Shooting`
- Apply one separator and spacing rule catalogue-wide.

## QA boundary

Do not alter material, waterproofing, standards, or performance claims without source-product verification.
