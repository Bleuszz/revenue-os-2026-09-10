# Fictional catalogue-workflow example

This is a fictional, non-client demonstration of the £399 catalogue-workflow pilot. It is not a testimonial, paid engagement, conversion result, or claim about commercial performance.

The example deliberately includes:

- `DEMO-001`: complete approved source fields and a clean structure check;
- `DEMO-002`: missing optional source fields, surfaced as human-review flags rather than invented facts; and
- `DEMO-003`: an approved-benefit field containing a prohibited claim, causing the structure check to fail.

Files:

- `templates/catalogue_input_demo.csv`: fictional buyer-supplied source fields;
- `templates/catalogue_output_demo.csv`: generated review-only catalogue drafts; and
- `docs/samples/catalogue-workflow-report.md`: generated human-review report.

Every generated row remains labelled `HUMAN FACTUAL REVIEW REQUIRED`. Nothing is automatically published.
